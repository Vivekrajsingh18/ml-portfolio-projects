# Machine Learning Portfolio Projects

A collection of supervised machine learning projects built with Python and scikit-learn.

## Projects

### 1. California Housing Price Prediction

- **Type:** Regression
- **Dataset:** California Housing dataset from scikit-learn
- **Models:** Linear Regression, Ridge Regression, Lasso Regression
- **Methods:** Exploratory Data Analysis (EDA), feature scaling, cross-validation, and hyperparameter tuning
- **Evaluation Metrics:** MAE, RMSE, and R²

### 2. Breast Cancer Classification

- **Type:** Binary Classification
- **Dataset:** Breast Cancer Wisconsin dataset from scikit-learn
- **Model:** Logistic Regression
- **Methods:** Stratified train-test split, feature scaling, cross-validation, and hyperparameter tuning
- **Evaluation Metrics:** Accuracy, precision, recall, macro F1-score, and confusion matrix

## Tech Stack

- Python
- NumPy
- Pandas
- Matplotlib
- scikit-learn
- Jupyter Notebook

## Setup and Installation

1. Clone or download this repository.
2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Launch JupyterLab:

   ```bash
   jupyter lab
   ```

4. Open the notebooks and run the cells from top to bottom.

## Results

Evaluation metrics will be added after running and validating both notebooks. Only verified cross-validation and test-set results will be reported.

## Limitations

These projects are intended for educational purposes and demonstrate basic supervised machine learning workflows. The housing predictions are not guaranteed real-world prices, and the breast cancer classifier is not intended for medical diagnosis.
